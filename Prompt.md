Промпт для кодировщика Python
Роль: Ты — опытный Python-разработчик мобильных приложений.

Задача: Разработать мобильное приложение-напоминалку под Android (с возможностью сборки под iOS) на Python.

Функциональные требования
1. Периодичность напоминаний
Пользователь задаёт интервал через удобный UI (слайдер или поля ввода).

Диапазон: от 1 минуты до 24 часов.

Единицы выбора: минуты и часы.

Настройки интервала сохраняются между запусками приложения.

2. Активные часы (окно напоминаний)
Пользователь задаёт диапазон времени суток, в который разрешены напоминания (например, с 10:00 до 22:00).

Указываются два времени: «начало» и «конец» окна (часы + минуты, формат 24 ч).

Если текущее время вне активного окна — напоминания не срабатывают; таймер не накапливает «пропущенные» срабатывания, а возобновляется с началом следующего активного окна.

Если окно переходит через полночь (например, 22:00 → 06:00) — это тоже должно корректно поддерживаться.

Возможность полностью отключить ограничение по времени (чекбокс «Работать круглосуточно») — тогда напоминания идут всегда.

3. Момент срабатывания напоминания
Поверх всех окон (в т.ч. когда приложение свёрнуто) появляется полноэкранное изображение.

Одновременно проигрывается звуковой сигнал (зациклено до реакции пользователя).

Кнопки: «Ок / Я сделал» (остановить) и «Отложить» (snooze, например +5 минут).

4. Настраиваемый контент
Пользователь может выбрать картинку из галереи устройства или из предустановленных.

Пользователь может выбрать звук из аудиофайлов устройства или из предустановленных.

Пути к выбранным файлам сохраняются в конфиге и используются при следующем срабатывании.

5. Управление
Кнопки: Старт / Пауза / Стоп таймера.

Индикация текущего статуса, времени до следующего напоминания и текущего активного окна.

Автозапуск службы напоминаний после перезагрузки устройства (желательно).

Технические требования
Язык: Python 3.10+

Фреймворк: Kivy + KivyMD (или BeeWare/Toga — обоснуй выбор).

Android-специфика: используй plyer / pyjnius для:

системных уведомлений;

foreground service (чтобы система не убивала напоминалку);

доступа к файлам (галерея, аудио) через Android Storage Access Framework.

Логика времени: все проверки «активного окна» выполняй через datetime и учитывай локальную таймзону; не используй наивные сравнения строк.

Хранение настроек: JSON-файл в приватной директории приложения (app_settings.json). Структура должна включать: interval_minutes, active_hours_enabled, active_from, active_to, image_path, sound_path.

Звук: kivy.core.audio.SoundLoader или pygame.mixer.

Сборка: предоставь buildozer.spec для сборки APK.

Код модульный: ui.py, scheduler.py, notifier.py, settings.py, time_window.py (логика активных часов).

Обязательно предусмотри обработку разрешений Android (уведомления, доступ к файлам, работа в фоне, точные будильники на Android 12+).
