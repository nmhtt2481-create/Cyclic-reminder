# Cyclic Reminder

Приложение на Kivy для циклических напоминаний. Приложение работает локально, хранит настройки в JSON-файле и поддерживает активное окно времени с точностью до минут.

## Возможности

- настройка интервала напоминаний в часах и минутах;
- активное окно напоминаний, например с `09:30` до `23:15`;
- поддержка окон, переходящих через полночь;
- режим работы круглосуточно;
- русскоязычный интерфейс;
- напоминание с изображением и зацикленным звуком;
- пауза звука и откладывание напоминания на пять минут;
- сохранение настроек между запусками приложения;
- сборка Android-приложения в формате `.apk`.

## Требования для запуска на компьютере

- Python 3.10 или новее;
- Kivy;
- KivyMD;
- Plyer.

Установка зависимостей:

```powershell
python -m pip install kivy kivymd plyer
```

Запуск:

```powershell
python main.py
```

## Сборка Android APK

Сборка выполняется в Linux или через WSL. Buildozer официально не предназначен для нативной сборки Windows.

Для Android-сборки нужны Linux или настроенный WSL2, Python 3, Buildozer и Java JDK. Android SDK/NDK Buildozer установит при первом запуске.

Установка Buildozer в Linux/WSL:

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip python3-venv
python3 -m pip install --user buildozer cython
```

Перейдите в каталог проекта и запустите debug-сборку:

```bash
cd /mnt/c/Users/user/Documents/Cyclic\ reminder
buildozer android debug
```

При первом запуске Buildozer скачает Android SDK/NDK и другие компоненты, поэтому сборка может занять значительное время.

Готовый APK появится в каталоге `bin/`. Найти его можно командой:

```bash
find bin -name '*.apk'
```

Установка на подключённое Android-устройство:

```bash
adb install -r bin/*.apk
```

Для повторной сборки после изменения исходников используйте `buildozer android debug`. Для полной очистки промежуточных файлов:

```bash
buildozer android clean
buildozer android debug
```

## Разрешения Android

Приложение запрашивает разрешения, необходимые для уведомлений, выбора медиафайлов, фоновой работы и точных напоминаний. На Android 13 и новее разрешение на уведомления нужно подтвердить при первом запуске.

## Настройки

Настройки сохраняются в приватный файл `app_settings.json` и содержат `interval_minutes`, `active_hours_enabled`, `active_from`, `active_to`, `image_path` и `sound_path`. Время начала и окончания хранится в формате `HH:MM`.

## Кнопки и элементы управления

- **Старт** — сохраняет введённые значения интервала и активного окна, затем запускает напоминания. На Android дополнительно запрашивает разрешение на уведомления и перезапускает фоновый сервис, чтобы он перечитал настройки. Через 5 секунд главное окно сворачивается, а приложение продолжает работать в фоне. Статус меняется на «Запущено».
- **Пауза таймера** — временно останавливает отсчёт до следующего напоминания, не закрывая приложение. Статус меняется на «Пауза».
- **Стоп** — полностью останавливает таймер и звук, закрывает открытое окно напоминания, меняет статус на «Остановлено» и завершает приложение вместе с Android-сервисом. Следующее напоминание появится только после нового запуска приложения ярлыком.
- **Выбрать картинку** — открывает выбор файла изображения (`PNG`, `JPG` или `JPEG`). Выбранная картинка будет показана в окне напоминания. На Android перед выбором может быть запрошен доступ к изображениям.
- **Выбрать звук** — открывает выбор звукового файла (`MP3`, `WAV` или `OGG`). Выбранный звук будет воспроизводиться при напоминании. На Android перед выбором может быть запрошен доступ к аудиофайлам.
- **Флажок «Работать круглосуточно»** — отключает ограничение активным окном времени. Если флажок снят, напоминания работают только между значениями «с» и «до»; поддерживается переход через полночь.

### Кнопки окна напоминания

Когда наступает время напоминания, открывается окно с выбранной картинкой и следующими кнопками:

- **Ок / Я сделал** — останавливает звук, закрывает текущее окно и сворачивает приложение. Цикл напоминаний при этом не прерывается.
- **Пауза звука** — приостанавливает воспроизведение звука, оставляя окно напоминания открытым.
- **Отложить +5 минут** — останавливает звук, закрывает окно и планирует следующее напоминание через пять минут.

После каждого срабатывания звук запускается снова, а картинка показывается до нажатия «Ок / Я сделал», но не дольше 30 секунд. Если кнопку не нажать, по истечении 30 секунд окно напоминания и главное окно приложения сворачиваются. Приложение продолжает работать в фоне до следующего срабатывания.

### Кнопка выбора файла

В окне выбора картинки или звука кнопка **Выбрать** сохраняет отмеченный файл и закрывает окно. Если файл не выбран, окно остаётся открытым, а прежний путь не изменяется.
